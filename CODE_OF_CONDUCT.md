# Code of conduct

Project discussions must remain professional and focused on the work.

Participants are expected to:

- address technical arguments rather than people;
- provide reproducible evidence for factual claims;
- respect privacy, copyright and dataset licenses;
- avoid harassment, discrimination, threats and sustained disruption;
- accept a maintainer decision to close an unsafe or out-of-scope proposal.

Report conduct concerns privately to the maintainers through the repository security contact. Maintainers may edit or remove content, lock discussions, reject contributions or restrict participation when this policy is violated.
