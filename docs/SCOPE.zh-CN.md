# 场景与功能限制

本文定义 0.38 的识别边界。扩大边界前必须增加对应测试和独立真实扫描验证。

## 输入要求

- 印刷的西方五线谱扫描件或由扫描件生成的清晰图片。
- 导入前必须保证页面方向正确。
- 支持轻度扫描噪声、照明不均和普通书页弯曲。
- 带透视畸变的照片、严重遮挡、手写谱和任意屏幕截图不属于高准确度边界。

## 支持的乐谱结构

- 单谱表器乐谱。
- 常见钢琴和键盘谱。
- 一个键盘声部最多可使用四个物理谱表，包括临时附加谱表和 ossia。
- 键盘谱表可包含独立同时声部、声部交叉，以及跨谱表音符、连梁、连音线和延音线。
- 纵向排列的多个单声部器乐声部。
- 钢琴与多个单声部器乐声部的组合谱。
- 每个谱表系统最多 16 个物理谱表。

合奏中的每个声部拥有独立时间轴，音符的横向位置不会强制不同乐器同时发声。

## 页面处理

同一任务中导入的多份扫描件视为同一乐谱的连续页面，最终输出一份 MXL/MusicXML。PDF 按原页码展开。分别扫描的独立分谱不会被重建为一份总谱。

## 记谱范围

目标包括谱号、调号、拍号、音符、休止符、和弦、连音符、变音记号、延音线、连音线、连梁、力度、渐强渐弱、常见演奏法、装饰音、速度文字、排练文字、反复和小节线结构。

输出以音乐语义为目标，不保证复刻原始字体、间距和分页。

## 不支持

- 打击乐和无固定音高记谱
- TAB
- 歌词
- 和弦符号和数字低音
- 不符合既定谱表时间轴结构的浓缩谱或 divisi 谱表
- 真正的复合节拍体系
- 微分音和图形记谱
- 手写谱

稳定版标签覆盖程序行为、文件格式和发布包，不表示每个识别符号都必然与原稿一致。识别准确度声明必须以作品隔离的真实扫描证据为依据；未通过结构检查的输出需要人工复查。
